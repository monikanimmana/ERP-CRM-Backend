TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════

Issue: "ECONNREFUSED 127.0.0.1:5432"
→ PostgreSQL not running. Start it and try again.

Issue: "database "erp_crm_db" does not exist"
→ Run: createdb erp_crm_db

Issue: "relation \"users\" does not exist"
→ Run: npm run db:migrate

Issue: "Missing required env variable: DATABASE_URL"
→ Check .env file exists with DATABASE_URL set.

Issue: "Port 4000 already in use"
→ Kill process or change PORT in .env

Issue: "npm: command not found"
→ Install Node.js v20+ from nodejs.org

More help: See README.md "Troubleshooting" section
