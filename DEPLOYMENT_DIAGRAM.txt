                            DATA FLOW - HOW IT WORKS
                            =======================

USER INTERACTION:
    1. User opens: https://erp-crm-frontend.vercel.app
    2. React app loads in browser
    3. User enters credentials
    4. Frontend sends POST to backend
    5. Backend verifies password
    6. Backend queries PostgreSQL
    7. Backend returns JWT token + user data
    8. Frontend stores token, shows dashboard
    9. All future requests include JWT
    10. Backend validates JWT, returns data


AUTHENTICATION FLOW:
    Frontend          Backend           Database
        │                │                  │
        │─ POST /login──▶│                  │
        │                │─ Query user──▶   │
